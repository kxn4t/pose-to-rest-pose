# Pose to Rest Pose

シェイプキーとドライバーを保持したまま、現在のポーズをレストポーズとしてワンクリックで適用するBlenderアドオン。

## 機能

- **ワンクリック操作**: ポーズメニューから直接、現在のポーズをレストポーズとして適用
- **シェイプキー保持**: 値、スライダー範囲、ミュート状態、相対キー、頂点グループを含むすべてのシェイプキーを維持
- **ドライバーサポート**: シェイプキーのドライバーを保持し、自己参照を自動更新
- **複数メッシュ対応**: 同じアーマチュアの影響を受ける複数のメッシュを処理

## インストール方法
1. Blenderの「編集」→「プリファレンス」→「エクステンションを入手」を開きます
2. 「リポジトリ」→「+」→「リモートリポジトリを追加」をクリックします
3. URL に `https://kxn4t.github.io/blender-extensions/index.json` を入力します
4. 「Pose to Rest Pose」を検索してインストールします

## 使用方法

### 基本的な使用方法
1. アーマチュアを選択して**ポーズモード**に入る
2. アーマチュアを希望のポーズに配置
3. **ポーズ > 適用 > 現在のポーズをレストポーズとして適用**を選択

アドオンは自動的に以下を実行します:
- 選択したアーマチュアをターゲットとするアーマチュアモディファイアを持つすべてのメッシュを検出（他シーンのメッシュを含む）
- すべてのシェイプキーとそのプロパティを保持
- 現在のポーズをアーマチュアのレストポジションに適用
- すべてのモディファイアとドライバーを復元

## 技術的詳細

### シェイプキー処理
このアドオンは[SKkeeper](https://github.com/smokejohn/SKkeeper)のアルゴリズムを使用して以下を実行します:
- 各シェイプキーの一時的なコピーを作成
- 現在のポーズでアーマチュアモディファイアを適用
- シェイプキーをベースメッシュに転送
- すべてのシェイプキーのプロパティと関係を維持

### ドライバー処理
- シェイプキーの既存のドライバーを自動検出
- ドライバーの式と変数を保持
- シェイプキーデータへの自己参照を含むドライバー参照関係を復元

## 要件
Blender 4.2.0 以上

> **注意:** Blender 3.6〜4.1 をお使いの方は [v0.3.0](https://github.com/kxn4t/pose-to-rest-pose/releases/tag/v0.3.0)（最終レガシー版）をご利用ください。

- メッシュは対象アーマチュアごとに1つのアーマチュアモディファイアのみ持つこと

## 制限事項とベストプラクティス

### モディファイアの順序
メッシュデータに適用されるのはアーマチュアモディファイアのみです。その他のモディファイアはそのまま残るため、頂点数を変更するモディファイア（ミラー、サブディビジョンサーフェスなど）があっても頂点数の不一致は起きません。
- ✅ **推奨**: アーマチュアモディファイア → その他のモディファイア
- ❌ **非対応**: 変形モディファイア → アーマチュアモディファイア

アーマチュアモディファイアの前に変形モディファイア（ディスプレイス、波、シュリンクラップなど）がある場合は、処理を中止します。ポーズをレストポーズとして適用すると、これらのモディファイアが元の形状ではなくポーズ後の形状に作用するようになり、結果が変わってしまうためです。

アーマチュアモディファイアの前にミラーモディファイアがある場合は処理できますが、正しい結果になるのは左右対称のポーズのみです。ポーズが適用されるのは元の半身だけで、反対側はそれを左右反転した形になるためです。この場合は警告が表示されます。

### 共有メッシュデータ
- 共有（リンク）メッシュデータを持つオブジェクトには対応していません。複数のオブジェクトが同じメッシュを共有している場合（Alt+D で作成した場合など）、先にシングルユーザー化が必要です（オブジェクト > 関係 > シングルユーザー化 > オブジェクトとデータ）。

### シーン範囲
- `pose.armature_apply()` はアーマチュアのデータブロック自体を変更するため、アドオンは全シーンを横断して対象アーマチュアを参照するすべてのメッシュを処理します

### 保持されないデータ
以下のデータはこのアドオンでは保持されません:
- **シェイプキーのアニメーションデータ**: シェイプキーに設定されたキーフレーム、アクション、NLA ストリップは転送されません。シェイプキーのアニメーションを作成する前にこのアドオンを適用してください。
- **アーマチュアモディファイアのカスタムプロパティ**: アーマチュアモディファイア自体に追加されたカスタムプロパティは失われます。標準的なモディファイア設定（ボリューム保持、頂点グループ、スタック位置など）は復元されます。
