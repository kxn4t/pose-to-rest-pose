# Pose to Rest Pose

シェイプキーとドライバーを保持したまま、現在のポーズをレストポーズとしてワンクリックで適用するBlenderアドオン。

## 機能

- **ワンクリック操作**: ポーズメニューから直接、現在のポーズをレストポーズとして適用
- **シェイプキー保持**: 値、スライダー範囲、ミュート状態、相対キー、頂点グループを含むすべてのシェイプキーを維持
- **ドライバーサポート**: シェイプキーのドライバーを保持し、自己参照を自動更新
- **複数メッシュ対応**: 同じアーマチュアの影響を受ける複数のメッシュを処理

## 要件
Blender 4.2.0 以上

> **注意:** Blender 3.6〜4.1 をお使いの方は [v0.3.0](https://github.com/kxn4t/pose-to-rest-pose/releases/tag/v0.3.0)（最終レガシー版）をご利用ください。

## インストール方法
1. Blenderの「編集」→「プリファレンス」→「エクステンションを入手」を開きます
2. 「リポジトリ」→「+」→「リモートリポジトリを追加」をクリックします
3. URL に `https://kxn4t.github.io/blender-extensions/index.json` を入力します
4. 「Pose to Rest Pose」を検索してインストールします

## 使用方法
1. アーマチュアを選択して**ポーズモード**に入る
2. アーマチュアを希望のポーズに配置
3. **ポーズ > 適用 > 現在のポーズをレストポーズとして適用**を選択

### 自動処理フロー
アドオンは自動的に以下を実行します:
- 選択したアーマチュアをターゲットとするアーマチュアモディファイアを持つすべてのメッシュを検出（他シーンのメッシュを含む）
- すべてのシェイプキーとそのプロパティを保持
- 現在のポーズをアーマチュアのレストポジションに適用
- アーマチュアモディファイアとドライバーを復元

## 制限事項と注意点

### モディファイアの順序と対応状況
本アドオンはメッシュデータに対してアーマチュアモディファイアのみを処理します。他のモディファイアは保持されるため、ミラーやサブディビジョンサーフェスなどがあっても頂点数の不一致は発生しません。

| 構成 | 挙動 | 詳細 |
| :--- | :--- | :--- |
| **アーマチュア → その他のモディファイア** | ✅ 正常動作（推奨） | 理想的な設定順序です。 |
| **変形 → アーマチュア** | ❌ 処理中断 | ディスプレイスやシュリンクラップなどの変形モディファイアが前にある場合、ポーズ適用後に結果が変わるため安全のために処理を中止します。 |
| **ミラー → アーマチュア** | ⚠️ 警告表示 | 処理自体は可能ですが、ポーズがかかるのは元の半身だけで、反対側はそれを左右反転した形になるため、**左右対称のポーズのときのみ**正しい結果になります。 |

> **注意:** 同じアーマチュアを指すアーマチュアモディファイアは、メッシュごとに1つまでです。

### その他の制限事項
- **共有メッシュデータ（リンク複製）**: `Alt+D` などでメッシュデータを共有しているオブジェクトには対応していません。事前に「オブジェクト > 関係 > シングルユーザー化 > オブジェクトとデータ」で独立させてから実行してください。
- **マルチシーン影響**: `pose.armature_apply()` はアーマチュアデータ自体を変更するため、blend ファイル内の全シーンを調べて対象メッシュを一括処理します。

### 保持されないデータ
以下のデータは適用時にリセットまたは削除されるためご注意ください:
- **シェイプキーのアニメーションデータ**: シェイプキーに設定されたキーフレーム、アクション、NLA ストリップは転送されません。シェイプキーのアニメーションを作成する前にこのアドオンを適用してください。
- **アーマチュアモディファイアのカスタムプロパティ**: アーマチュアモディファイア自体に追加されたカスタムプロパティは失われます。標準的なモディファイア設定（ボリューム保持、頂点グループ、スタック位置など）は復元されます。

## 技術的詳細

### シェイプキー処理
このアドオンは[SKkeeper](https://github.com/smokejohn/SKkeeper)のアルゴリズムをベースに以下を実行します:
- 各シェイプキーの一時コピーを作成
- 現在のポーズ状態のままアーマチュアモディファイアを適用
- ベースメッシュへ各シェイプキーを転送
- すべてのシェイプキーの各プロパティおよび相互関係を再構築

### ドライバー処理
- シェイプキーに関連付けられた既存ドライバーを自動検出
- ドライバーの式や変数を損なわずに保持
- シェイプキーデータ本体への自己参照を含め、元の依存関係を正しく再接続
